# 💬 ChatApp

A **realtime chat application** built with **React**, **Node.js (Express)**, **Socket.IO**, and **MongoDB**.  
This app allows multiple users to chat instantly, with messages stored persistently in MongoDB.  

---

## ✨ Features

- 🔄 **Realtime Messaging** – Powered by Socket.IO for instant updates.  
- 🗂️ **Persistent Chat History** – Messages stored in MongoDB.  
- 🎨 **Modern React UI** – Clean and responsive frontend.  
- ⚙️ **Express API Backend** – Handles data, authentication (if enabled), and persistence.  
- 🚀 **Easy Setup** – Minimal steps to run locally.  

---

## 🛠️ Tech Stack

- **Frontend**: React, HTML, CSS, JavaScript  
- **Backend**: Node.js, Express.js, Socket.IO  
- **Database**: MongoDB (Local or Atlas)  
- **Other**: REST APIs, WebSockets
